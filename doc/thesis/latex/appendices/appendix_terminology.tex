\chapter{Terminology}

\textbf{Paxos:} the original Multi-Paxos replication backend in Mako.

\textbf{Multi-Raft:} one Raft group per partition.

\textbf{Single-Raft:} one consolidated Raft log, with one local replica running in
each process and partition identity carried in each command.

\textbf{ReplayPool:} pool of Mako replay workers that execute heavy follower replay
outside the Raft apply staging thread.

\textbf{1:1 ReplayPool:} benchmark setting where \code{MAKO\_REPLAY\_THREADS} equals the
number of Mako worker threads.

\textbf{Preferred leader election:} a configured Raft replica that the system biases toward
leadership when it is live and sufficiently caught up.

\textbf{Simulated disk:} a source-tagged disk model that charges writes by
bytes, bandwidth, latency, and queueing delay.
