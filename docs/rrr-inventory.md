## Caveats

- The decl span is a brace-counted heuristic, not a full C++
  parse. Inline-comment braces and string-literal braces are
  handled but template angle brackets aren't. Spans within
  ~5% of the truth.
- The bucket is a first cut. Anything in `trivial` should be
  reviewed before migration — the script can't see whether
  the decl is referenced by name from a template instantiation
  elsewhere, which would block DSL-ification.
- File-scope free functions, typedefs, and constants are not
  enumerated here (the existing GEN-block coverage already
  catches the simple-constant pattern; what's left is per-decl
  signal-heavy).
