# Mako local C ABI revision 0 contract (historical)

Revision 0 is superseded. The current implementation reports revision 1 and
required-native callers reject revision 0. The old draft remains available in
Git history; it is not a deployment or compatibility contract.

Use the normative
[revision-1 contract](mako-local-abi-v1.md) and the declaration source of truth
in [`mako_local_abi.h`](../../src/mako/storage/mako_local_abi.h).
