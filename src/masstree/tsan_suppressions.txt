# TSan suppressions for Masstree tests.
#
# Activate by exporting TSAN_OPTIONS before running a test binary:
#
#   export TSAN_OPTIONS="suppressions=$(realpath src/masstree/tsan_suppressions.txt):halt_on_error=0"
#
# The suppressions below qualify known data-race UB in Masstree's inherited
# optimistic-concurrency machinery. Readers race against writers on node fields
# (permuter, version, keylenx, and others), then use a version-counter retry to
# discard inconsistent observations. That is the algorithm's intended x86
# implementation model, but the later retry does not make the plain C++ races
# language-defined. Filename-wide suppressions can also hide a new race in the
# same frames, so every TSan pass is qualified by this reviewed debt.

# Masstree internal lock-free traversal / split / remove paths.
race:masstree_insert.hh
race:masstree_remove.hh
race:masstree_split.hh
race:masstree_struct.hh
race:masstree_scan.hh
race:masstree_tcursor.hh
race:masstree_get.hh
race:nodeversion.hh
race:kpermuter.hh

# Compiler intrinsics for fence / relax — surfaced incidentally.
race:masstree/compiler.hh
